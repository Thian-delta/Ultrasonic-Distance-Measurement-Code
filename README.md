1. Ultrasonic Distance Measurement

An embedded system using an STM32 microcontroller is designed to automate the capture of the velocity profile of a gravity racer. It utilizes ultrasonic sensors and electromagnet control for precise measurements.

2. Code

The code, developed in C using the STM32 IDE, is programmed into the STM32 microcontroller. It includes not only the main code but also .ioc files for pin assignments and settings for clock and baud rate.

3. Electronic Schematics

Detailed schematics of the electronic circuit, incorporating the ultrasonic sensor, electromagnet, and microcontroller, can be found in the `electronic-schematics` folder.
